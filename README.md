# 鼓楼 · Gulou

可交互的南京大学鼓楼校园。步行、骑行、滑翔，在昼夜与晴雨中探索建筑、街道和校园故事。

**在线体验** · [作者](https://wang-jiahao.github.io/) · [赞赏](#支持这个项目)

无需安装或注册，支持电脑与手机浏览器。

![鼓楼校园预览](docs/images/gulou.png)

## 为什么做鼓楼

从2022级开始，本科生都需要在鼓楼寻根一年，大家或多或少都对鼓楼有些感情。

这个项目在 **GPT 6 Astra 的协助下** 开发，希望把熟悉的校园变成打开网页就能探索的空间，也用一个能亲手玩的作品，让大家直观看到，今天的 AI 已经能把一个想法推进到怎样的完成度。

学校 Minecraft 社团的校园复刻给了我启发。对于想随时逛逛校园的人，我希望再提供一种无需购买游戏、安装客户端或连接服务器的方式，让同学、校友和对南大感兴趣的人都能轻松开始。

## 怎么玩

| 场景 | 操作 |
| --- | --- |
| 行走与观察 | **WASD / 方向键**移动，**Shift**加速，**空格**跳跃；鼠标拖动观察，**V**切换视角 |
| 骑行与飞行 | 靠近单车按 **E**上下车；**F**起飞 / 降落，飞行时**空格 / Ctrl**升降 |
| 地点与互动 | **M**打开地图、搜索与传送；**I**看地点故事；**E**坐下、起身或进行球类互动，**R**重置球 |
| 画面与环境 | **T**调时间天气，**P**拍照，**H**隐藏界面；右上角 **⛶**切换全屏 |
| 暂停与返回 | **Esc**释放鼠标 / 打开设置；设置里可返回开始页，再从原位置继续 |

手机使用左侧摇杆移动、右侧拖动转向，其余操作由屏幕按钮完成。设置中可切换人物、穿搭和画质，也可导入自己的音乐；音频只在浏览器本地播放，不上传。

## 在校园里

- **地标与街道**：北大楼、大礼堂、汉口路门、教学区、图书馆、校史博物馆、运动场和南园生活区，沿校园道路自由探索。
- **自己的路线**：散步、骑行或滑翔；通过地图搜索楼名，在熟悉的门前停留，或找一个新的拍照角度。
- **流动的环境**：晴日下午、黄昏与夜晚自然交替，支持雨天与手动调整时间。
- **校园故事**：阅读来自学校与院系资料的地点介绍，在大纛坪升降国旗，在松林休憩点坐一会儿。
- **随手游玩**：运动场足球、篮球练习、男女形象与三套穿搭、照片保存和本地音乐播放。

场景依据资料近似重建，部分建筑细节、尺寸与植被位置仍有偏差。欢迎熟悉校园的同学指出问题、提供参考。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| TypeScript + Vite | 游戏逻辑、界面、资源处理与静态构建 |
| Three.js / WebGL2 | 三维渲染、PBR材质、阴影、植被与天气 |
| Rapier | 人物运动、楼梯与场景碰撞、球类刚体 |
| glTF / GLB + Meshopt | 人物、树木与模型资源的组织和压缩 |
| Web Audio / HTML Audio | 环境声、音量控制与本地音乐 |

建筑的资料核对、建模与通行验证过程，见[建筑是怎样做出来的](docs/building-process.md)。

## 本地运行

建议Node.js 22.18或更新版本，并安装pnpm。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

```bash
npm run typecheck
npm run lint
npm run check:assets
npm run build
npm run preview
```

构建产物位于 `dist/`，可部署到支持静态网站的服务；子路径构建与资源排除规则见[部署说明](docs/deployment.md)。不要直接上传整个工作目录。
