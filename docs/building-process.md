# 建筑是怎样做出来的

**先确定平面关系，再做可见细节。** 校园平面图、官方VR、开放地图与实拍资料被对应到统一的校园坐标。楼体占地、道路、院落、校界和入口分开描述，避免把公共街道当成校内围墙，也不把参考照片的透视比例当成实测尺寸。

**普通建筑使用规则生成，重点建筑单独建模。** 普通楼体由占地轮廓挤出，按楼层与立面方向布置窗格、门框、檐口、空调、阳台和侧牌；北大楼、图书馆、博物馆、汉口路门等则使用独立构件与专门的布局代码。复杂占地保留内院和孔洞，门廊、架空通道与宿舍凹进入口按局部轮廓裁切，避免“画了一扇门，后面还是实心墙”。

**模型、材质和标牌各司其职。** 梁柱、屋顶、台阶、栏杆与窗框使用网格几何；石材、砖墙、玻璃和金属通过颜色、法线与粗糙度贴图表现；校名、楼牌和电子屏使用程序绘制的纹理或几何文字。原始参考照片和视频用于核对，不直接塞进游戏当整面墙贴图。

**可行走的校园需要另一套碰撞结构。** 视觉模型与Rapier碰撞体分开组织，重点检查门洞、台阶、斜坡、骑行出口和公共道路。相机也会检测场景遮挡；可见的围墙、门禁和通行空间需要与玩家实际能走的位置相符。

**在细节与渲染成本之间做取舍。** 重复构件按材质合批，树木使用实例化与距离层级，普通立面细节按区域显示，距离切换时短暂淡入淡出，减轻飞行时窗框等成组跳变；模型通过Meshopt压缩。局部改动保留对照基线，再检查几何、碰撞、截图与帧耗时。资源更小或绘制次数更少，并不自动等于运行更流畅。
