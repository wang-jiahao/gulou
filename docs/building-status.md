# 建筑精修与对齐清单

**“已精修”只指表中列出的部位，不表示整栋建筑已精确还原。** 大多数尺寸由照片、VR与校园图近似拟合；被遮挡的立面、背面、内部空间和未辨清的小字仍可能不准确。文字内容正确、安装位置正确和书法字形一致是三项不同的工作，下面分别说明。

## 如何补充与维护

反馈时尽量说明**楼名、哪一侧、具体不一致的部位**。若有新资料，优先提供能把招牌／入口与周围道路或相邻楼放在同一画面里的照片；文字特写用于核字，远景用于核位置。无需重复发送已提供的原图。

后续每次精修应同步更新本清单：写明实际核对的部位、仍有的误差，并将已经拿到资料的事项从“需资料”移入“待修改”，完成后再记录成果。原始照片与视频只作本地参考；公开贡献请注明来源与使用许可。
