# 门禁定向感应与南园纠错 — v0.110

旧逻辑为人行闸3.4米、车道杆10米圆形距离触发。现改为各自门向的狭长通道检测：向门移动的法向分量至少占总移动65%，附近静止/横穿不请求开门；真正占用通道时保持开启，清空后延迟0.55秒再关。游戏传入实际骑行/飞行状态，飞行不触发。

骑行按车头0.95米、闸翼摆幅0.53米和约0.25秒开门时间预留距离。正常步行人行闸约1.25米触发，4.5m/s骑行约2.60米，9m/s快骑约3.65米；范围始终受通道宽度和方向限制。不是回到周围大范围感应。保持原门/围墙实体碰撞，不新增可穿校园缺口。

## 修复中实际发现的问题

- 首次缩小感应区仍有斜向漂移误触发：横向每走1米、向门漂2厘米即可抬杆。
- 自行车从闸翼摆出的方向进入时，车头先碰到未开闸翼；9m/s车头到闸面只有45.1%开度，单看骑手中心会漏掉问题。
- 加法向比例和车头提前量后，测试路径动态网格重叠为0，快骑车头到面开度至少99.665%。低空飞行通过真实状态排除，不只根据高度猜测。
