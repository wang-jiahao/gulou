## Astra 标准价折算

[官方定价页](https://developers.openai.com/api/docs/pricing)，核对日期 2026-10-10，币种美元，以下均为**每百万 token**。采用 Standard 费率；如果中转实际采用 Fast、Ultrafast 或自有价格，实际扣款会不同。

| 类别 | 单次输入 ≤272,000 | 单次输入 >272,000 |
| --- | ---: | ---: |
| 普通输入 | $10.00 | $20.00 |
| 缓存读取 | $1.00 | $2.00 |
| 缓存写入 | $12.50 | $25.00 |
| 输出（含推理） | $50.00 | $75.00 |

按每次请求的输入长度选择费率，再汇总：短上下文 18,370 次、长上下文 513 次，最大单次输入 637,264 token。

普通输入 = 总输入 − 缓存读取 − 缓存写入。三类输入互斥；缓存写入不是额外叠加在普通输入之上的附加费。输出已经包含推理 token，不能再把推理用量加一遍。

费用 = Σ（普通输入 × 对应输入单价 + 缓存读取 × 对应读取单价 + 缓存写入 × 对应写入单价 + 输出 × 对应输出单价）÷ 1,000,000。使用原始数值计算，最后显示到美分。

**合计 $5,640.68**：短上下文 $4,946.91，长上下文 $693.77。这是按官方 Standard 单价折算的模型费用，不含中转折扣、税费与外部工具费用。

## 更新方式

运行 `npm run metrics -- --refresh-usage`，只扫描本机与当前项目目录匹配的任务日志，重新统计用量并刷新 README 和本页；也可显式传入日志路径。运行 `npm run metrics` 也会自动刷新匹配项目的本地日志；本机没有匹配日志时才沿用最近一次用量快照。原始日志、消息内容和本机路径不写入本页或 README。
